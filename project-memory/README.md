# Постоянная память проекта LowSpeedCentrifuge3

Дата актуализации: 2026-06-11

Эта папка хранит краткую устойчивую память о проекте: архитектурные решения, runtime-пути, правила работы с Node-RED flow и особенности операторского UI. Это не замена полной документации в `docs/`, а быстрый справочник перед изменениями.

## Как пользоваться

Перед доработкой проекта читать в таком порядке:

1. `current-state.md` - что сейчас реализовано и где лежит источник истины.
2. `technical-notes.md` - технические особенности, ограничения и правила правки.
3. `operator-ui-notes.md` - поведение операторских вкладок и пользовательские сценарии.
4. `docs/project-state.md` - расширенное состояние проекта.
5. `flows.json` - окончательная истина по текущему Node-RED flow.

## Главный принцип

Если документация и `flows.json` расходятся, приоритет у `flows.json` и текущего кода `packages/nc3-elmo-machines`.
