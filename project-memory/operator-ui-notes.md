# Память по операторскому UI

Дата актуализации: 2026-06-11

## Общие правила UI

- Все production-вкладки имеют remote-control баннер.
- При отсутствии права управления поля и кнопки должны блокироваться.
- View-only данные, журнал и протоколы должны оставаться доступны.
- `Мониторинг` существует, но руководство оператора 2026-06-11 описывает вкладки кроме него.

## Угловая скорость

Основная вкладка оператора.

Ключевые блоки:

- верхняя панель: `Drive Init`, `БПП`, статус сценария, статус инициализации;
- `Управление двигателем`: `Motor On`, `Motor Off`, `STOP`, `HOME`;
- статус привода: `MO`, `SO`, `MS`, `SR` (чипы с расшифровкой кода усилителя), диапазон, скорость, положение;
- параметры движения: скорость профиля, ускорение, замедление;
- сценарный режим: `Работа по сценарию`, выбор файла, `Старт`, `Пауза`, `Продолжить`, `STOP`, `Аварийный стоп`;
- протокол: `Открыть протокол`, `Закрыть протокол`, длительность записи, raw-data, `Запись`;
- команды скорости: `JP`, `JV`;
- команды перемещения: относительное и абсолютное перемещение.

Тонкости поведения:

- ручной `Drive Init` = только контрольный оборот (двигатель должен быть включен); полный init сценарий делает сам;
- статусы init: "Инициализация" / "Инициализация проведена" / "Инициализация не проведена" + warning-баннер, если не подтверждена;
- `БПП` заблокирован, пока `MO || SO` (снекбар "Смена разрешения невозможна"); после переключения init сбрасывается;
- `Продолжить` сценария повторяет текущий шаг с начала (остаток выдержки не восстанавливается);
- ошибка сценария отменяет активную запись и шлет `drive_stop`.

## Сценарии

UI-редактор находится на странице `Угловая скорость`.

Основные действия:

- `Обновить` каталог;
- выбрать файл `.scn`;
- `Новый сценарий`;
- редактировать `Имя файла`;
- редактировать шаги `Скорость, град/с` и `Выдержка, с`;
- `Добавить шаг`;
- `Сохранить`;
- `Удалить`.

Во время активного сценария редактирование блокируется.

## БУН

Отдельная страница `Tilt Control`. Макет 2 колонки: слева — текущий угол + режим + ввод/уставка, справа — тормоз + управление наклоном + карточка скрипта.

Основные элементы:

- выбор режима;
- текущий угол;
- ввод целевого угла в DMS/deg/rad (`type=text`, без браузерных стрелок);
- `Set`, `Stop`;
- переключатель тормоза;
- `Release`, `Zero`, `Slow Up`, `Slow Down` (с tooltips);
- карточка скрипта `nc3_bun.py`: индикатор статуса + `SYS_STATE` + `Запустить/Перезапустить/Остановить`.

Тормоз внешней оси уходит в ELMO `OL[2]`.

## БЕП

Отдельная страница `Gap Control` (flow `BEP flow`). Главный элемент — крупная **схема установки** (шпиндель + датчики), датчики пронумерованы (1–4 + `ОС`), единый нейтральный цвет (синий/серый), без разноцветной раскраски. График каналов и управление — справа, таблица конфигурации — снизу.

Основные элементы:

- индикатор статуса скрипта (`работает`/`не отвечает`/`ожидание` по свежести данных), uptime, packet count, error;
- схема установки (hero) с показаниями у каждого датчика + легенда;
- график каналов (бары единого цвета, подписи по номерам);
- управление скриптом `nc3_bep.py`: `Запустить/Перезапустить/Остановить` (`bep_process`);
- измерения: `Start`, `Stop`, `Start single`, `Start CAPDAC` (`mqtt_cmd`);
- `board_num`, `capdac_val`;
- таблица конфигурации каналов: label, CAN ID, position, enabled, `Save`.

## Настройка

Общие настройки:

- remote-control;
- коррекция угла;
- raw-data по умолчанию;
- язык;
- допуск готовности скорости;
- длительность data-файла;
- режим сохранения угла в протокол.

Расширенные настройки:

- диапазон угла наклона;
- диапазоны скоростей `high`/`low`;
- скорость переключения энкодера;
- коэффициенты БЕП;
- круглограмма/аэростатическая опора;
- строки калибровки энкодера.

В текущем UI проверка пароля advanced-панели отключена в коде шаблона.

## Журнал

Подвкладка `Журнал`:

- фильтры `info`, `record`, `warning`, `error`;
- `Обновить`;
- `Очистить`;
- persistent-файл `C:\NC3\logs\events.jsonl`.

Подвкладка `Протоколы`:

- список протоколов;
- просмотр protocol/data файла;
- график data-файла;
- режимы `Тики` и `Десятичный угол`;
- выбор разрешения при пересчете;
- `Построить`, zoom, reset, pan.
