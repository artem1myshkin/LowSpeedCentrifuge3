  • имя файла сценария
  • номер шага / общее число шагов

Scenario Runtime

ScenarioFileService

Ведет каталог C:\NC3\scenarios, читает и сохраняет .scn файлы для UI-редактора.

scenario_catalog scenario_load
↓

ScenarioManager

  • держит state machine сценария
  • вычисляет текущий шаг
  • решает, нужен ли switch range
  • стартует timeout после ACK set_jv
  • ожидает достижения допуска
  • запускает таймер удержания
  • инициирует автоматическую запись в протокол
running_step holding paused emergency_stop
↓

ScenarioReadyEvaluator

Сравнивает целевую скорость с velocity_deg_per_sec; для low это значение берется из буфера PX/TM.

ELMO Control

CommandHandler

  • AC, DC, JV, BG для шага сценария
  • ST для стопа / аварийного стопа
  • OL[1] + sequence для смены диапазона
  • Drive Init после смены диапазона

Аварийная Остановка

ScenarioManager фиксирует состояние, отменяет активную запись, отправляет ST, сохраняет текущий шаг и причину останова, затем отдает в UI состояние emergency_stop.

Продолжение

После снятия причины аварии Продолжить запускает текущий шаг заново. Восстановление остатка выдержки пока оставлено вне реализации.

Автосмена Диапазона

Если шаг требует другого диапазона, runtime останавливает движение, переключает диапазон, выполняет Drive Init и затем продолжает тот же шаг без потери сценарного контекста.
